# Customer_Behavior_analysis
data analysis project showcasing customer behavior analysis using python , sql , power bi ,EDA

This project demonstrates an end-to-end data analytics pipeline: loading a dataset with Python, performing EDA and data cleaning, running SQL queries, building a Power BI dashboard, and presenting insights in a Gamma PPT.​

Tools
Python (Pandas, NumPy, Matplotlib/Seaborn) for loading data, EDA, and cleaning.​

MySQL for writing and running SQL queries on the cleaned data.​

Power BI for data modeling, measures, and dashboard creation.​

Gamma for turning insights and visuals into a slide deck for business stakeholders.​

Steps
Load & Inspect Data (Python)

Import CSV/Excel data into a Jupyter notebook.

Inspect schema, data types, missing values, and basic statistics.

EDA & Data Cleaning (Python)

Handle missing values, duplicates, and outliers.

Create exploratory visualizations to understand trends, seasonality, and key drivers.​

Create SQL-ready Tables

Push the cleaned dataset into MySQL.

Design basic schemas (fact and dimension tables where relevant) and run SQL queries to answer business questions.​

Build Power BI Model & Dashboard

Connect Power BI to the SQL database or cleaned export.

Create relationships, DAX measures, and visuals aligned with the business problem.​

Insights & Presentation (Gamma)

Export key visuals and metrics.

Build a concise Gamma PPT summarizing problem, approach, insights, and recommendations.​
